# F19 — Независимая поставка

## Context & business goal
Как engineer, хочу: Менять сервис без полного релиза.

## Preconditions
M13; images pinned. Выполнить проверку auth/session/tenant до доступа к данным. Пользовательские команды идут через gateway, service credentials не заменяют customer identity.

## Expected behavior / Main scenario
Pipeline builds changed service + reverse contract dependents; deploy digest, smoke, rollback.

## Alternative scenarios
Failed readiness -> old deployment remains.

## Error scenarios
Migration destructive in same release -> blocked. UI показывает стабильный problem code, correlation ID и разрешённое действие. Не раскрывает чужие идентификаторы или stack trace.

## Acceptance criteria
When deploy Notification only; Then six core service digests stay unchanged; rollback restores prior image without DB loss.

Записать автоматизированный тест с ID F19, fixture version и фактическим результатом. Снимок UI — дополнение к проверке состояния, а не доказательство транзакции.

## Dependencies and implementation task
M13; этап M16; экраны: operations. Отдельный PR с review контракта и failure evidence. Для повторных команд и событий действуют общие правила contracts/README.md.
