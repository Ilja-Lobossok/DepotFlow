# ADR-003: Inventory temporal exclusion

Status: Accepted; date 2026-10-11; assignment design baseline.

## Context / decision

Allocation correctness belongs a single SQL transaction and owned database, including maintenance blocks.

## Alternatives / consequences

App-only check races; Redis locks can expire and split ownership. SQL lock contention is real cost.

## Verification / reconsideration trigger

100 simultaneous overlaps and repair races; observe GiST exclusion and row locks.

Implementation may supersede this decision only with a new ADR preserving required learning outcomes and updating contracts, diagrams, task evidence and coverage. No undocumented deviation.
