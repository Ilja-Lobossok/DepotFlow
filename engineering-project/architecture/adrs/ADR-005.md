# ADR-005: REST first, no core gRPC

Status: Accepted; date 2026-10-11; assignment design baseline.

## Context / decision

Human-readable contracts and troubleshooting outweigh unmeasured throughput benefit.

## Alternatives / consequences

gRPC comparative lab permitted, generated clients and transport debugging add complexity.

## Verification / reconsideration trigger

Measure same availability query in lab and record decision, no artificial polyglot sprawl.

Implementation may supersede this decision only with a new ADR preserving required learning outcomes and updating contracts, diagrams, task evidence and coverage. No undocumented deviation.
