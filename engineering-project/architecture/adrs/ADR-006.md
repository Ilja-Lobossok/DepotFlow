# ADR-006: Keycloak authentication and Tenancy authorization

Status: Accepted; date 2026-10-11; assignment design baseline.

## Context / decision

OIDC avoids bespoke password system, authoritative membership protects business commands.

## Alternatives / consequences

Gateway-only auth insufficient; JWT role revocation stale. Lookup availability reduces write availability.

## Verification / reconsideration trigger

Role revocation after open form prevents mutation; fail closed Tenancy down.

Implementation may supersede this decision only with a new ADR preserving required learning outcomes and updating contracts, diagrams, task evidence and coverage. No undocumented deviation.
