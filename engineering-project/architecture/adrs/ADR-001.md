# ADR-001: Seven bounded services and monorepo

Status: Accepted; date 2026-10-11; assignment design baseline.

## Context / decision

Owner boundaries reflect money, physical assets and irreversible warehouse action. Monorepo makes contract review discoverable while own builds/releases prevent deployment coupling.

## Alternatives / consequences

Single small commercial team might choose monolith; goal here explicitly distributed practice. Separate repos increase workflow costs.

## Verification / reconsideration trigger

Proof F19 separate digests and DB grant denial; reconsider Notification split if ownership costs exceed benefit.

Implementation may supersede this decision only with a new ADR preserving required learning outcomes and updating contracts, diagrams, task evidence and coverage. No undocumented deviation.
