# ADR-010: Local-first cloud practice

Status: Accepted; date 2026-10-11; assignment design baseline.

## Context / decision

All mandatory work runnable local; IaC concepts learned in isolated VM/provider simulation, AWS optional.

## Alternatives / consequences

Simulation does not prove real IAM/network or managed cloud behavior; cloud-specific claims need authorized sandbox evidence.

## Verification / reconsideration trigger

Audit labels local vs live, includes cost assumptions and destroy evidence if sandbox used.

Implementation may supersede this decision only with a new ADR preserving required learning outcomes and updating contracts, diagrams, task evidence and coverage. No undocumented deviation.
