# ADR-007: Compose first, Kubernetes final lab

Status: Accepted; date 2026-10-11; assignment design baseline.

## Context / decision

Sequential implementation keeps seven-service target while deferring scheduler overhead until integrity proven.

## Alternatives / consequences

Kubernetes needed for final deployment exercise, not a proof of reliability; one-node cluster remains single failure domain.

## Verification / reconsideration trigger

Probe/rollback, DB restore and own network grants must be tested.

Implementation may supersede this decision only with a new ADR preserving required learning outcomes and updating contracts, diagrams, task evidence and coverage. No undocumented deviation.
